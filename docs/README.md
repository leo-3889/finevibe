behaviour it describes; when a change invalidates a claim here, that doc is
updated in the same commit.

One note for readers of a fresh clone: several docs cite `todos/…` paths. That
directory is the maintainer's **local-only work queue** (gitignored), so those
citations resolve only in the maintainer's tree — the contracts above are the
public record.
