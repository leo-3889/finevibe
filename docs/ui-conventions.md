Locale contract: components initialize before `appState.load()` and `initI18n()` run, so anything rendering translated strings or preference-driven visibility must re-apply on `state-loaded`/`preferences-changed` (or `onLocaleChange` from `src/renderer/i18n.ts`); `initI18n()` re-emits the persisted locale every launch precisely for this. Theme and zoom are the exception: `src/renderer/index.ts` applies them before the first paint from the synchronous `store:startup-prefs` channel (`window.finevibe.store.startupPrefs()`, served from the main-process state cache), because waiting on the async `store:load` paints a frame in the wrong theme. Nothing else may read persisted state synchronously.
# UI conventions

Use the existing renderer components, CSS theme variables, modal manager and custom controls. Avoid native `<select>` elements and hard-coded colors. The project overview uses Gridstack and persists `ProjectRecord.overviewLayout` per project. Widget factories are registered in `src/renderer/components/project-tab/widgets/widget-registry.ts`, including readiness, provider tools, GitHub PRs/issues, team, Kanban, sessions, favorites, usage stats and top files by tokens. Tab groups render as a `.tab-group` wrapper widget inside the tab strip (`components/tab-bar/tab-list.ts`): the label carries the group name + member count (full text in `title`, `tab.group.tooltip`), colors come only from the `--tab-group-1..6` theme variables via `color-mix` tints, and the label's inline rename input is a tab-bar text field — shortcut suppression follows the `.tab-name input` field-guard semantics (`split-layout.ts` rename-focus guard includes `.tab-group-name input`).

Open file reader tabs through `openFileReaderChecked` so a missing file does not leave a stale tab. Rendered Markdown links are intercepted to prevent navigation away from the Electron app document. `src/renderer/i18n.ts` handles English and Chinese with English fallback; only the supported UI areas are translated today.

When planning a new feature, consider whether a Preferences setting is useful. Update tests and these contracts when adding a component, widget or lifecycle behavior.

The Add-project modal (`promptNewProject`) treats its path field as a git-URL field when `detectGitCheckoutUrl` (`src/shared/git-url.ts`) recognizes a GitHub/Codeberg clone URL: the confirm button label swaps in place on `#modal-confirm` (showModal's `confirmLabel` is fixed at open), the name field fills from the repo, path autocomplete is suppressed (a URL's dirPart is not a filesystem path), and confirm runs the clone through `fs:cloneRepo` before `addProject`. The `defaultProjectsFolder` preference (General section, read-only row set through the `fs.browseDirectory` picker) pre-fills the path as `<folder>/<name>` under the same manual-edit-guard style used for name auto-fill; the clone destination is main-gated like the pre-project picker (home tree / known roots, explicit confirm outside home).

`src/renderer/shortcuts.ts` suppresses app shortcuts while a text field owns the keyboard (input/textarea/select/contenteditable outside a `.xterm` pane) and while a modal is open — a visible `#modal-overlay` (shared modal manager) or any visible `.modal-overlay` root (`modal-shell` dialogs; zoom + Help pass through) (`6af0c7a`). Popover overlays outside that guard rely on typing suppression through their focused input; the shared overlay roots are share, team-picker, team-picker-detail, quick-open, session-palette, flow-picker and send-menu. A new overlay in that set must focus a text input on open, or app shortcuts stay live behind it. The shared `#modal-overlay` dialogs record the focused element on open and `closeModal()` restores it after the hide (only when it is still connected and not `body`), so a dialog opened from a live input — the Ask AI composer's "send to custom session" path into the New Session modal — hands keyboard focus back on Cancel/Create. The New Session modal stacks its rows Name → Persona → Prompt → Arguments/keep → Env/keep, with Provider first and Profile last when they are offered.

File-reader previews render bounded pages (2,000 lines / 128 Ki characters) rather than a DOM for the entire file. The partial-preview notice explains that search covers the displayed page and long lines may be truncated. Previous/Next and go-to-line navigate the source without splitting every line into a retained array. Both raw and rendered Markdown use the same page budget. Untracked Git diff previews reject inputs over 256 KiB, over 5,000 lines, or containing NUL bytes, with an explanatory message.

Terminal attachments are paths, and every paste route injects the same content with one precedence: file lists, then plain text, then a rich-text copy's markup source (only when it carries no plain text), then a materialised image path, then a literal Ctrl+V passthrough for flavors neither side translates; an empty clipboard sends nothing. A file dropped on a session terminal or a project shell types its path into the PTY (`attachFileDropHandler`). Injected file paths are shell-quoted per the PTY's platform before typing — POSIX single quotes, Windows double quotes (`quoteShellPath`) — so a name with spaces arrives as one argument (`9b206f9`); a Windows path containing `"` is refused and named in the pane alert banner, mirroring the spawn path's rejection of quote-bearing arguments (see [security boundaries](security-boundaries.md)). A native paste event hands over File objects (screenshots, Explorer/Finder file copies); when main reads the clipboard (Windows Ctrl+V, the context menu) it decodes the file-list formats — `FileNameW`, `CF_HDROP` (DROPFILES `fWide` at offset 12), the Finder plist and `text/uri-list` — and writes pathless clipboard images to the paste temp directory under a generated name (`pasteIntoTerminal` and `attachImagePasteHandler` in `src/renderer/components/terminal-utils.ts`, `clipboard:readForPaste` in `src/main/ipc-handlers.ts`). The file list outranks the clipboard's plain text because a file-manager copy leaves the file name there as a by-product. The provider reads the file, which keeps one contract across all six CLIs — do not add per-provider attachment handling.

Tab names carry display-only text prefixes through one seam: `tabNamePrefix()` in `components/tab-bar/tab-list.ts` composes the `DIFF`/`P2P`/`WEB` badges and the provider icon before the escaped name; the SSH connection prefix (`<span class="tab-ssh-prefix">ssh host - </span>`, `sshPrefix()` beside it) joins that composition in the full render and in both surgical patches (`updateTabStatus`, `patchTabMetadata`), never in `session.name`. The host comes from the transient `src/renderer/session-ssh.ts` registry and is always `esc()`-escaped — registry values can originate from PTY bytes. The "hover while inferring" effect reuses the global `@keyframes pulse` (`styles/tabs.css`) via `.tab-name.ssh-inferred` (1.5 s, `working` only) instead of defining a new animation; the same reuse idiom is `.card-status-dot.working` in `styles/kanban.css` and the inline `animation` in `components/help-shared.ts`. The tooltip suffix (`tab.tooltip.sshHost`) is localized (en + zh-CN); the prefix text itself is a user-specified literal and stays untranslated.

See [performance and resource limits](performance.md) for the current user-facing limits. Preview search is page-local; navigation resets search decorations. Bounded rendered Markdown may end inside a block at a page boundary.

The text of a paste arrives through the native paste event on every platform (clipboard plan P1): Windows `Ctrl+V` reaches Chromium's paste handler and xterm writes the text itself, so a plain-text paste performs no clipboard IPC at all; main's `clipboard:readForPaste` serves only what the event cannot carry — file-only copies, the context-menu Paste, markup-only copies, and images. Pasted text beyond 8 Mi characters is cut at the bound and the pane banner names the limit (P4, `textTruncated`) — a capped copy is never silently lossy.
