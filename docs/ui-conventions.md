Locale contract: components initialize before `appState.load()` and `initI18n()` run, so anything rendering translated strings or preference-driven visibility must re-apply on `state-loaded`/`preferences-changed` (or `onLocaleChange` from `src/renderer/i18n.ts`); `initI18n()` re-emits the persisted locale every launch precisely for this. Theme and zoom are the exception: `src/renderer/index.ts` applies them before the first paint from the synchronous `store:startup-prefs` channel (`window.vibeyard.store.startupPrefs()`, served from the main-process state cache), because waiting on the async `store:load` paints a frame in the wrong theme. Nothing else may read persisted state synchronously.
# UI conventions

Use the existing renderer components, CSS theme variables, modal manager and custom controls. Avoid native `<select>` elements and hard-coded colors. The project overview uses Gridstack and persists `ProjectRecord.overviewLayout` per project. Widget factories are registered in `src/renderer/components/project-tab/widgets/widget-registry.ts`, including readiness, provider tools, GitHub PRs/issues, team, Kanban, sessions, favorites, usage stats and top files by tokens.

Open file reader tabs through `openFileReaderChecked` so a missing file does not leave a stale tab. Rendered Markdown links are intercepted to prevent navigation away from the Electron app document. `src/renderer/i18n.ts` handles English and Chinese with English fallback; only the supported UI areas are translated today.

When planning a new feature, consider whether a Preferences setting is useful. Update tests and these contracts when adding a component, widget or lifecycle behavior.

`src/renderer/shortcuts.ts` suppresses app shortcuts while a text field owns the keyboard (input/textarea/select/contenteditable outside a `.xterm` pane) and while a modal is open — a visible `#modal-overlay` (shared modal manager) or any visible `.modal-overlay` root (`modal-shell` dialogs; zoom + Help pass through) (`6af0c7a`). Popover overlays outside that guard rely on typing suppression through their focused input; the shared overlay roots are share, team-picker, team-picker-detail, quick-open, session-palette, flow-picker and send-menu. A new overlay in that set must focus a text input on open, or app shortcuts stay live behind it.

File-reader previews render bounded pages (2,000 lines / 128 Ki characters) rather than a DOM for the entire file. The partial-preview notice explains that search covers the displayed page and long lines may be truncated. Previous/Next and go-to-line navigate the source without splitting every line into a retained array. Both raw and rendered Markdown use the same page budget. Untracked Git diff previews reject inputs over 256 KiB, over 5,000 lines, or containing NUL bytes, with an explanatory message.

Terminal attachments are paths, and every paste route injects the same content with one precedence: file lists, then plain text, then a rich-text copy's markup source (only when it carries no plain text), then a materialised image path, then a literal Ctrl+V passthrough for flavors neither side translates; an empty clipboard sends nothing. A file dropped on a session terminal or a project shell types its path into the PTY (`attachFileDropHandler`). Injected file paths are shell-quoted per the PTY's platform before typing — POSIX single quotes, Windows double quotes (`quoteShellPath`) — so a name with spaces arrives as one argument (`9b206f9`, see [security boundaries](security-boundaries.md)). A native paste event hands over File objects (screenshots, Explorer/Finder file copies); when main reads the clipboard (Windows Ctrl+V, the context menu) it decodes the file-list formats — `FileNameW`, `CF_HDROP` (DROPFILES `fWide` at offset 12), the Finder plist and `text/uri-list` — and writes pathless clipboard images to the paste temp directory under a generated name (`pasteIntoTerminal` and `attachImagePasteHandler` in `src/renderer/components/terminal-utils.ts`, `clipboard:readForPaste` in `src/main/ipc-handlers.ts`). The file list outranks the clipboard's plain text because a file-manager copy leaves the file name there as a by-product. The provider reads the file, which keeps one contract across all six CLIs — do not add per-provider attachment handling.

See [performance and resource limits](performance.md) for the current user-facing limits. Preview search is page-local; navigation resets search decorations. Bounded rendered Markdown may end inside a block at a page boundary.
